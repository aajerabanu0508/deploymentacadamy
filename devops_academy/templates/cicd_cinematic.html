Automated Testing & SAST

The runner checks out the commit and restores cached wheels. pytest executes unit tests while Bandit and pip-audit analyze source ASTs and package CVEs.

If even one test fails or an unpatched CVE is identified, the pipeline terminates immediately — halting vulnerabilities before deployment.

$ actions/checkout@v4
$ bandit -r ./app -ll
✓ 0 high/critical issues
$ pip-audit -r requirements.txt
✓ 26 packages clean
$ pytest -n auto --cov=app
✓ 64 passed, 94.6% cov

Scan, Sign & Push Image

Before pushing to Amazon ECR, Trivy scans the container OS layers for zero-day vulnerabilities. Cosign then cryptographically signs the image digest using GitHub OIDC tokens.

Tag immutability and KMS encryption guarantee that production artifacts cannot be altered or poisoned.

$ trivy image --severity HIGH,CRIT ...
✓ 0 CVEs found
$ cosign sign --yes ecr.aws/myapp@sha256...
✓ Rekor log entry: #28941092
$ docker push 123.dkr.ecr.aws/myapp:abc1234
✓ Published to ECR (Immutable)

Canary Deploy & Zero Downtime

Database migrations execute first via Alembic. The Application Load Balancer then routes a 10% canary traffic slice to the new green tasks while synthetic monitoring checks HTTP 5xx error budgets.

With healthy SLOs confirmed, traffic shifts to 100% and old blue containers are drained cleanly. Zero downtime, zero customer impact.

$ alembic upgrade head
✓ DB schema synchronized
$ aws elbv2 set-weights --green 10%
Monitoring p99 latency: 38ms...
$ aws elbv2 set-weights --green 100%
✓ 100% Live — 0 downtime rollback safe
